# Tarkov Helper

**「あと何件やろう？ どこから進めよう？」を、信頼度・LL・タスクの解放条件から考える管理アプリ。**

## v0.2 — 次の目標が分かるトレーダー管理

前提タスクをたどるだけでなく、**次のタスクが出るまであと何件か、次のLLまで信頼度がどれだけ足りないか**を確認できます。トレーダー単体ページは上部の情報を固定し、タスク行だけをスクロールするシンプルな一覧です。

- **次のLLまで**：現在の信頼度を編集し、必要信頼度・PMCレベルとの差を確認。今できるタスクの報酬から件数の目安を表示します。
- **次の完了数条件**：判明している残り件数を短く表示し、対象タスクへ絞り込めます。
- **タスクは1行ずつ**：概要・FiR・信頼度報酬を確認し、完了チェックで記録。詳しい攻略は行のWikiリンクから確認できます。
- **通知はトースト**：完了や確保数の記録を画面下に通知します。完了直後の取り消しもできます。

**全トレーダーの連携グラフは引き続き利用できます。** トレーダーをまたぐ前提・後続関係を見たいときは、全トレーダー表示で経路をたどれます。

```mermaid
flowchart LR
    A[前提タスク] --> B[途中のタスク]
    B --> C[クリアしたいタスク]
    C --> D[次に解放されるタスク]
```

_図は依存関係の表示イメージです。実際の解放条件には、PMCレベルやトレーダーのLLなども含まれます。_

## 主な機能

| 機能             | できること                                                                        |
| ---------------- | --------------------------------------------------------------------------------- |
| タスクグラフ     | 前提・後続タスクをハイライトし、つながりの深さに沿って表示                        |
| トレーダー別表示 | 信頼度・LL目標・解放までの残り件数をまとめて確認し、進めるタスクを選択            |
| 全トレーダー表示 | トレーダーをまたいでつながるタスクラインをまとめて確認                            |
| 解放条件の確認   | PMCレベル・LL・信頼度・前提タスクなどから受注可否を判定。不明な条件は「要確認」に |
| 進捗の記録       | タスク行のチェックで完了・取り消しを操作。信頼度と完了カウントも連動              |
| FiR・Collector   | 必要アイテムを画像で確認し、確保数を記録                                          |
| マップ別タスク | マップごとに全トレーダーの今できるタスクを確認。解放待ちも切り替えて表示 |
| レイド準備       | マップを選び、受注中タスクの未達目標やキー・マーカーの候補を確認                  |
| プロフィール     | 通常・PvE・シーズンの進捗を分けて保存。プレステージに応じたNew Beginningも表示    |
| バックアップ     | 進捗の書き出し・復元、データ版の固定、セルフワイプに対応                          |

日英のタスク名・アイテム名・IDで検索でき、お気に入りのタスクは星と金色の枠で強調します。トレーダーページではマップ名でも検索できます。

## 使い方

1. [アプリ](https://apfeltksg.github.io/tarkov-helper/)を開き、ゲームモード・PMCレベル・プレステージなどを設定します。
2. トレーダーを選び、現在の信頼度を入力して、次のLLまでの不足を確認します。
3. タスク行のチェックで完了を記録します。直後のトーストから取り消せます。FiR表示を押すと、その行で確保数を編集できます。

件数は判明している条件だけから計算します。信頼度の件数は現在進められるタスクを報酬順に選んだ目安で、完了難度や追加解放までは予測しません。未解明の条件は「要確認」のまま残します。[計算と表示の仕様](docs/TRADER_DASHBOARD.md)。

### 全トレーダーの連携グラフ

| グラフの操作                      | 動作                               |
| --------------------------------- | ---------------------------------- |
| カーソルを合わせる                | 前提・後続タスクと経路をハイライト |
| 左クリック                        | 完了を記録／取り消し               |
| Shift＋クリック、または右クリック | 詳細をポップアップで表示           |
| 背景をドラッグ／ホイール          | 移動／拡大・縮小                   |

半透明のノードは通常クリックで完了できません。詳細から条件を確認してください。条件を自動判定できるタスクは「条件自動判定／条件を無視して受注可能にする」、要確認タスクは「ゲーム内に出ていない／出ている」を選べます。

## 保存とデータについて

- 進捗はブラウザ内に保存されます。ゲームと自動同期はしません。端末を変えるときやブラウザの保存データを消す前に、バックアップを書き出してください。
- ゲームデータは6時間ごとに更新を確認し、全モードの検証・テスト・ビルドに成功した変更を自動公開します。データ更新ごとのPR・手動マージは不要です。補足データの配信障害時は検証済みの正常版を使い、データの破損や検証失敗時は公開中のサイトを保持します。
- 未解明の内部条件など、完全に判定できない条件は「要確認」として残します。実際にゲーム内で表示されたかを記録できます。
- ハイドアウトページは現在無効です。上部のボタンは灰色で表示されます。

データの取得元：

- [tarkov.dev API / The Hideout](https://github.com/the-hideout/tarkov-api) — タスク・アイテム・トレーダーなどのゲームデータ
- [tarkov-data-overlay / TarkovTracker.org](https://github.com/tarkovtracker-org/tarkov-data-overlay) — LL分類・タスク配布グループ・一部のプレステージタスクなどの補足データ

詳しくは[データ更新手順](docs/DATA_PIPELINE.md)を参照してください。

## ローカルで動かす

Node.js 24を使用します。Next.js・React・TypeScript・React Flowで構成され、GitHub Pages向けに静的出力します。

```sh
npm ci
npm run dev
```

[http://localhost:3000](http://localhost:3000)を開いてください。ゲームデータはリポジトリに含まれているため、起動前に取得する必要はありません。

変更を確認する場合：

```sh
npm test
npm run lint
npm run typecheck
npm run build
```

ゲームデータを手動で更新する場合：

```sh
npm run data:update
```
