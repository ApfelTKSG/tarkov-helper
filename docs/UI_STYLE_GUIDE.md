# UIの共通ルール

調査の背景は [UI_DESIGN_REVIEW.md](UI_DESIGN_REVIEW.md) を参照。

## 目的

ゲームの横に置いて、LLまでの不足と進めるタスクを素早く読む。進捗判定や保存方式は表示から独立させる。

## 配色と部品

app/globals.css の --ui-* を共通の設定として使う。

| 役割 | 設定 |
| --- | --- |
| ページ背景 | --ui-canvas / #151718 |
| 入力・補助領域 | --ui-surface / #1c1f20 |
| 重なった領域・ホバー | --ui-raised / #25292b |
| 境界線 | --ui-line / #343a3c |
| 本文 | --ui-text / #eef0ed |
| 補助文字 | --ui-muted / #a6aeac |
| 選択・キーボードフォーカス | --ui-accent / #ccba8d |
| ロック行 | --ui-locked / #241c1c |
| 完了行 | --ui-complete / #19251e |

背景に対する本文と補助文字の計算上のコントラスト比は、それぞれ15.69:1、7.94:1。この確認は上記2組の色に限り、全画面のアクセシビリティ適合を表すものではない。

既存ページの移行中は .workspace 内のSlate色も同じ中立色へ対応させる。新しい用途ではページごとに別の色を増やさず、意味を持つ設定を共通側へ追加する。

- ui-control：入力と選択欄。基本高さ34px、文字14px、角丸4px。
- ui-nav-link：ページ移動。大きな囲いは使わず、選択中を下線で示す。
- ui-trader-link：トレーダー画像。選択中は細い枠、画像サイズは36px。
- ui-link：補助リンク。ホバーで強調する。
- ui-task-row：基本高さ64px。長い名前等で必要な場合は高さの増加を許す。
- ui-task-group：ロック・完了の見出し。色だけに頼らず名前と件数を表示する。

## 情報の順序

1. 選択中のトレーダーと現在LL。
2. 次のLLまでの信頼度・PMCレベル不足。
3. 完了数条件までの残りと、その候補。
4. タスク名、Map、概要、FiR、信頼度報酬、Wiki・受注設定。

件数の目安と確定条件を混同させない。判定根拠やデータ事情の長い説明は、必要な場所の補足へ置く。常用する操作は隠さない。

タスク名は14px、概要・Mapは13px、要求レベル等は12pxを基本とする。行を詰めるために文字を小さくしない。未選択のお気に入りは無彩色、選択中だけ強調する。正の信頼度報酬は通常の数値として揃える。

## 操作とページ間の統一

- PMC入力、ページ選択、設定、トレーダー選択は WorkspaceHeader に集約する。
- 設定はヘッダー内に常設し、開いても本文を押し下げない。
- タスク表は TaskTable、FiR編集は TaskFirPopover を共有する。
- ソートは見出しセル全体で操作可能にする。
- グラフにも同じ背景とヘッダーを適用する。短い操作ヒントは残し、長い説明は折りたたむ。
- 完了・ロック・要確認・失敗の判定、信頼度の台帳、バックアップ形式を見た目の都合で変更しない。

## 確認方法

Praporで文字・余白・行高を確認し、列ソート、ロック群の展開、FiR編集、設定開閉を確認する。マップ別では同じタスク表、全トレーダーでは共通ヘッダーが使われることを確認する。
