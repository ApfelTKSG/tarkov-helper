# v0.2 トレーダー進捗画面

単体ページは「次のLL」「次のタスク解放」「進めるタスク」の3つに整理する。全トレーダーの連携グラフは従来の深さ順表示を維持し、単体ページにはグラフ・切り替えボタンを表示しない。

## 信頼度とLL

既存プロフィールの信頼度・PMCレベル・LL指定から現在LLを求め、未指定なら次のLLを目標にする。LL2〜4など収録された目標を選ぶこともできる。必要信頼度とPMCレベルの不足は別々に表示する。現在値が未入力なら残りや件数を断定しない。最高LL、LLデータ未収録、トレーダー未解放も区別する。

今進められる当該トレーダーのタスクから、信頼度の正の純報酬を高い順に選び、不足分を埋める件数を目安として表示する。複数報酬はトレーダーごとに合算する。完了済み・失敗済みは再利用せず、候補は重複排除する。報酬合計が不足する場合や現在値が不明な場合は件数を表示しない。追加解放・排他的な進行・難度・所要時間は予測しないので、LLが必ず上がる件数とは扱わない。

未解放トレーダーの未受注タスクは通常の候補から除外する。ユーザーがゲーム内での受注を記録したものは尊重する。既存のLL指定・Jaeger/Ref解放タスク・信頼度台帳を利用し、新しいプロフィール形式へ移行しない。取引額など判定に含まれていない条件はゲーム内で確認する。

## 完了数による解放目標

既存のavailability判定結果のうち、検証済み・対象網羅・対応版一致のカウンターを使う。不足している `>=` と `>` の条件だけを残り件数に換算する。未解明・部分的なカウンター、上限・等号の条件を推測で件数にしない。

対象タスク集合と必要件数が同じ条件をまとめる。重なりのある複数条件の残り件数は足し合わせない。各対象タスクについて、別のLL・レベル・前提・未確認条件が残れば表示する。完了数の達成だけで解放が確定するとは表示しない。

現在進められる対象がある目標を優先し、その中で残り件数順に表示する。初期表示は3目標までで、残りは展開できる。目標から対象タスクへ絞り込める。対象がまだ受注できない場合は、解放待ちのタスクを表示する。他トレーダーのタスクが対象なら、そのタスクも名前付きで表示する。

## 操作と保存

タスクカードの名前・詳細ボタンで既存の詳細ダイアログを開く。完了ボタンは条件未達・未確認なら無効。条件無視やゲーム内での表示確認は既存の詳細メニューを使う。完了直後にはその場で取り消せる通知を表示し、完了一覧からも取り消せる。

完了と取り消しは既存の信頼度台帳を通す。現在値の手動修正を保持しながら、適用済み報酬だけを巻き戻す。件数は完了状態から再計算する。プロフィール・バックアップ・FiRのアイテム記録は共通のまま保持する。絞り込みと目標LLの選択は画面内の状態で、進捗としては保存しない。
