# v0.2 トレーダー進捗画面

単体ページはトレーダー情報・絞り込みを上に固定し、タスク行だけをスクロールする。全トレーダーの連携グラフは従来どおり維持する。

## レイアウト

画面全体を動的ビューポートの高さに収め、header・進捗・検索欄は縮めず、残りを行一覧に割り当てる。bodyをスクロールせず、行一覧のoverflow領域だけをスクロールする。列の見出しはその領域内でsticky表示する。狭い画面では同じ領域で横スクロールできる。プロフィール設定は上部の折りたたみパネルに置き、開いても一覧の配置を押し下げない。

大きな目標カードや説明段落は表示しない。上部には現在のLL・編集可能な信頼度・次のLLまでの不足・直近の完了数条件だけを短く表示する。タスク行は完了チェック、名前、概要とFiR、信頼度報酬、Wikiリンクで構成する。受注条件の切り替えは、必要な行にだけ表示する。

## LLと完了数

既存のプロフィールから現在LLと次の目標LLを求める。信頼度とPMCレベルの不足は別に扱い、信頼度が未入力なら必要件数を断定しない。今進められる当該トレーダーの正の信頼度報酬を高い順に選び、件数の目安とする。追加解放・排他的な進行・難度は予測しない。

完了数は検証済み・網羅・対応版一致のカウンターだけを使い、未達の>=と>を件数に換算する。対象が重なる条件を足し合わせない。進められる対象がある直近の条件を優先して表示する。他の解放条件まで達成したと断定しない。上部の件数を押すと対象タスクだけに絞り込める。

## タスク行とFiR

単体ページにはタスク詳細ダイアログを置かない。概要は必須目標の説明を1行にまとめ、攻略・詳細条件はWikiに任せる。全トレーダーの連携グラフの詳細は既存のまま残す。

FiRは必須のgiveItem目標だけを対象にし、find/giveの二重計上と任意目標を除外する。代替アイテムは候補ごとに数を増やさず、目標単位の共通カウントを使う。画像と確保数のプレビューを押すと行を展開し、既存のItemCounterで編集できる。数量が未収録なら推測で数を作らない。

確保数は従来と同じobjectiveCountsのtaskId:objectiveIdへ保存し、FiR一覧と共有する。アイテム確保によってタスクを自動完了せず、タスク完了によって確保数を自動追加しない。

## 記録と通知

完了・取り消しは既存の信頼度台帳を通す。受注できないタスクの完了チェックは無効。条件無視や「出ている／出ていない」は行内メニューで記録できる。プロフィール形式は変更しない。

完了・信頼度・FiR確保数・受注状態・お気に入りの記録成功後に、画面下の固定トーストで通知する。トーストはレイアウトを押し下げず、7秒で閉じる。ホバー・フォーカス中は自動で閉じない。完了トーストには取り消しボタンを付け、適用済みの信頼度だけを巻き戻す。保存に失敗した場合は成功通知を表示しない。
