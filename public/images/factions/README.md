# Faction marks

BEAR.webp and USEC.webp are Escape from Tarkov faction marks, obtained from the public assets in [TarkovTracker](https://github.com/tarkovtracker-org/TarkovTracker/tree/main/public/img/factions). Game marks belong to Battlestate Games. These assets are separate from application code.

Level badges use the `levelBadgeImageLink` field in the `playerLevels` data from the [tarkov.dev items feed](https://json.tarkov.dev/regular/items). No faction-specific rank variants are inferred: the level badge and the selected faction mark are shown together.
